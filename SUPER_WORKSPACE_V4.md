# Nexa AI — Super Workspace V4

This update is additive and builds on the Arabic/English tool localization already deployed.

## New capabilities

- Tool switcher inside the AI workspace.
- Per-tool AI modes:
  - Image: visible only, OCR, UI analysis, design critique, technical screenshot.
  - Document: summary, facts, action plan, risks.
  - Code: debug, review, explain, build.
  - Writing and analysis tools get purpose-built modes.
- Prompt Library with Arabic and English presets.
- Save custom prompts locally on the device.
- Local draft autosave.
- Local recent conversation restore for tool workspaces.
- Real AbortController Stop button.
- Voice input when the browser supports Web Speech Recognition.
- Read AI responses aloud with Speech Synthesis.
- Native Share button on supported phones.
- Drag and drop file support.
- Paste images directly from the clipboard in Image Analyzer.
- Focus Mode for a full-screen distraction-free workspace.
- Online/offline indicator and disabled sends while offline.
- Response latency indicator.
- Recently used tools row on AI Workspace.
- PWA install button when the browser exposes the install prompt.
- Keyboard shortcuts:
  - Enter = Send
  - Shift+Enter = New line
  - Alt+N = New conversation
  - Alt+F = Focus mode
  - Escape = Stop request / close panels

No new API keys and no new npm dependencies are required.
